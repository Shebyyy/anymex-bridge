   261→   261→

   429→   429→
   430→   430→**Request format** (JSON on stdin, newline-delimited):
   431→   431→```json
   432→   432→{"method": "loadExtensions", "args": {"folderPath": "/path/to/ext"}, "id": "123"}
   433→   433→```
   434→   434→
   435→   435→**Response format** (JSON on stdout, newline-delimited):
   436→   436→```json
   437→   437→{"id": "123", "status": "ok", "data": [...]}
   438→   438→```
   439→   439→
   440→   440→- Requests are matched by `id` (falls back to auto-increment)
   441→   441→- Stream responses use `status: "ok"` (data chunks), `status: "completed"`, `status: "error"`
   442→   442→- Default timeout: 60 seconds
   443→   443→- Cancellation: `{"method": "cancel", "args": {"id": "123"}}`
   444→   444→
   445→   445→### 4.4 Sidecar Process Startup
   446→   446→```bash
   447→   447→java -Dfile.encoding=UTF-8 -Dsun.stdout.encoding=UTF-8 \
   448→   448→     -Dsun.stderr.encoding=UTF-8 -Xms128m -Xmx512m -noverify \
   449→   449→     -jar /path/to/anymex_desktop_runtime.jar
   450→   450→```
   451→   451→
   452→   452→Startup detected by: stderr line containing `"AnymeX Sidecar Process Started"`
   453→   453→
   454→   454→### 4.5 Desktop Extension Install Flow
   455→   455→
   456→   456→1. APK downloaded from repo
   457→   457→2. `BridgeDispatcher().invokeMethod('convertApk', {apkPath, outJarPath})` → sidecar converts APK to JAR using embedded dex2jar
   458→   458→3. JAR saved to `{runtimeDir}/Extensions/Aniyomi/{pkgName}.jar`
   459→   459→4. `BridgeDispatcher().invokeMethod('loadExtensions', {folderPath})` → sidecar scans directory and loads all JARs
   460→   460→
   461→   461→### 4.6 Desktop vs Android Differences
   462→   462→
   463→   463→| Aspect | Android | Desktop |
   464→   464→|---|---|---|
   465→   465→| Runtime bridge | APK loaded via `DexClassLoader` (`MethodChannel('anymeXBridge')`) | JAR launched as subprocess (`SidecarBridge`) or JNI (`JniBridge`) |
   466→   466→| MethodChannel | `aniyomiExtensionBridge`, `cloudstreamExtensionBridge`, `kotatsuExtensionBridge` | `BridgeDispatcher` (sidecar stdin/stdout or JNI) |
   467→   467→| Aniyomi install | System package manager OR internal APK dir | APK→JAR conversion, stored in Extensions dir |
   468→   468→| CloudStream plugins | `.cs3` loaded from app data dir | Same `.cs3` loading via sidecar |
   469→   469→| Kotatsu plugins | `plugin.jar` loaded via MethodChannel | Same JAR loading via sidecar |
   470→   470→| Cookie/UA handling | `MethodChannel('anymeXBridge')` | `BridgeDispatcher` |
